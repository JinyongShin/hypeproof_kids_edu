# 지도안 품질 체크리스트

지도안이 **실행 가능 상태**가 되기 전 통과해야 하는 검사. 컴파일러 출력물과 강사 자작 지도안 모두에 동일하게 적용한다.

세 관문이 있고, **앞 관문에서 걸리면 뒤는 보지 않는다.**

## 관문 1 — 헌법 (하나라도 걸리면 폐기)

[[edu-constitution]] 위반 판정 체크리스트를 그대로 적용한다.

- [ ] 아동을 유형·프로파일로 분류하는 서술 없음 (B-3)
- [ ] 아동 간 비교·순위·상위 % 없음 (B-1)
- [ ] 단일 점수·종합 등급 없음 (B-2)
- [ ] "자격증" 표기 없음 (A-2)
- [ ] 전문가 실명이 근거 없이 등장하지 않음 (A-3)
- [ ] "뒤처진다"·"또래보다" 프레임 없음 (A-4)
- [ ] 아동 산출물·로그 수집에 동의 절차 선행 (A-5, B-4)
- [ ] 사용 모델이 연령 약관에 부합 (B-6)

## 관문 2 — 구조 (수정 후 재검)

- [ ] **평가 증거가 있고, 제3자가 볼 수 있는 물건이다** (성찰·소감은 증거가 아님)
- [ ] 성취기준이 관찰 가능한 동사로 쓰였다
- [ ] 본질적 질문이 **1개**다
- [ ] **금지 개입이 4계열 각각에 대해 최소 1개씩** 있다 (선취·대행·구조·압박)
- [ ] 모든 활동이 `activities/`의 원자를 참조한다 (인라인 신규 활동 없음)
- [ ] 활동 `requires` 선행 조건이 트랙 내 앞 차시에서 충족된다
- [ ] `forbids` 위반 없음
- [ ] [[placement-rules]] 배치 제약 위반 없음
- [ ] 활동 `duration_min` 합계가 회차 길이와 ±10분 내
- [ ] 발달구간 변형(Lv1/Lv2)이 명시되어 있다
- [ ] `safety: protocol` 활동이 있으면 대응 절차 링크가 있다
- [ ] 가정 연계 항목의 `ip_owner`가 확인되었다 (파트너 IP 침범 여부)

## 관문 3 — 실행 가능성 (경고, 차단은 아님)

- [ ] 흐름 표의 '교사' 열이 '학습자' 열보다 길지 않다
- [ ] 핵심 발문이 전부 열린 질문이다 (확인·유도 질문 없음)
- [ ] 사전 생성이 필요한 자산이 `prep_assets`에 명시되고 실재한다
- [ ] 정리 단계가 10분 이상 확보되었다
- [ ] 이 차시 증거물이 어느 수료 요건·측정 축에 연결되는지 명시되었다
- [ ] 처음 이 지도안을 받은 강사가 추가 설명 없이 실행할 수 있다

## 실패 시 처리

| 관문 | 처리 |
|---|---|
| 1 | **폐기.** 수정본을 새로 작성한다. 부분 수정으로 넘기지 않는다 |
| 2 | 수정 후 관문 1부터 재검 |
| 3 | 경고 기록 후 실행 가능. 다음 개정에 반영 |
