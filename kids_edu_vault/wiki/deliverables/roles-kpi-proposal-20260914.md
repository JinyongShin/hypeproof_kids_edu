## KPI — 공통 + 역할별

**전원 공통**: 완료한 약속 / 수락한 약속 · 기한 내 완료 / 해당 주 마감 약속 · **기한 지난 항목 수**. 증거·막힘·다음 행동을 붙인다.

| 역할 | KPI |
|---|---|
| 전략 | 주요 결정 대기 일수 · 제품별 목표 대비 실적 |
| 제품 | 합의한 산출물 완료 / 약속 (**구현·출시·실사용 상태 구분**) |
| 고객·사업 | 제안·후속 완료 / 약속 · **다음 약속이 기록된 고객 수** |
| 교육·연구 | 교육안·연구 기록 완료 / 약속 · 기한 내 전달 |
| 개발 | **인수 기준을 충족한** 산출물 / 약속 · 기한 내 전달 |
| 품질·운영 | 검증·운영 완료 / 약속 · **막힘 발견부터 공유까지 걸린 시간** |
| 브랜드·콘텐츠 | 실제 사용된 자료 수 · 후속 미팅 연결 고객 수 |
| 법무·IP | 검토 결과 전달 / 약속 · 기한 내 쟁점 공유 |
| 사업관리 | 기한 지난 미결 쟁점 · 검토부터 결정까지 걸린 시간 |

### 보고 형식

> 목표 / 실적 / **증거** / 차이의 이유 / 다음 행동·기한 / 필요한 결정

예: *"리허설 목표 3개 중 2개 통과. 증거 링크 첨부. 1개는 학생 권한에서 저장 실패. 목요일 재검증. 제공 범위를 줄일지 결정 필요."*

### 기록 원칙

- **미측정은 `—`/`미확인`.** 확인된 0과 구분한다
- 비율은 **분자·분모와 기간**을 함께
- **계약·청구·입금을 구분**한다
- **구현 완료·출시·실사용·효과 확인을 별도로** 기록한다
- 첫 **2주는 기준선 확보**. 그 후 역할별 목표를 합의한다
- 약속하지 않은 일이나 **전체 매출을 개인의 성과 의무로 돌리지 않는다**
- 겸임자는 범위를 표시하고 **같은 결과를 전체 합계에서 중복 집계하지 않는다**
