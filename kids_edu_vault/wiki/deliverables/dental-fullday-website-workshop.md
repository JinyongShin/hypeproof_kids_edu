# 치과 홈페이지 제작 풀데이 워크숍 (v0)

> 출처: [[2026-09-06-weekly-on-hypeproof]] §4, 신제형([[jehyeong]]) 제안. 채택됨.
> 상위 결정: [[dental-website-over-blog]]

## 왜 풀데이인가

**2시간 30분으로는 결과물이 안 나온다.** [[jiwoong-kim]]이 진행했던 웹페이지 만들기 세션에서 확인된 사실이다 — 배포까지는 되지만 **고객에게 퍼블리싱할 만한 퀄리티가 안 나온다**.

그렇다고 5회로 쪼갤 수도 없다. 원장들이 **주기적으로 다섯 번 같은 장소에 올 수 있는가**가 문제고, 회차를 연결하지 않으면 따로 들어서는 홈페이지가 완성되지 않는다. 왕복 이동도 그들에겐 비용이다.

→ **주말 하루를 통째로 빼서 실제 웹페이지 배포까지 끝낸다.**

## 구성 (3개 커리큘럼을 하나로 묶음)

| 시간 | 내용 |
|---|---|
| 오전 | HTML 기초 + **병원 정보 입력** ([[jiwoong-kim]] 진행분과 동일) |
| 오후 | **디자인 템플릿 적용** — 트래픽 상위 치과 홈페이지 5개를 테마별(보철·소아치과·임플란트 등)로 분석해 스킬로 만들어 둔다. 하나씩 적용해 보고 자기에게 맞는 것을 고른다 |
| 오후 | **배포** — Cloudflare CLI로 도메인 구매 → 연결 → 배포까지 자동화 |
| 16:00~ | 사이트맵 등록 등 마무리 |

### 설계 원칙 — 사진 몇 장만 얹으면 홈페이지가 나온다

> "그 사람들이 AI를 잘 쓰고 싶은 마음도 있겠지만 **홈페이지가 더 간절하다**. 페인포인트가 홈페이지에 있다."

디자인은 **임의로 미리 다 넣어 두고**, 참가자는 사진 몇 장만 넣으면 되게 만든다. 우리를 따라오면 진짜 홈페이지가 나온다. — [[boa-dental]] 피드백의 "요리교실식 운영"·"강사가 재료를 미리 준비"와 같은 노선이다.

### 기술 — Cloudflare CLI

**도메인 구매 이후 연결·배포까지 CLI로 전부 이어진다.** 참가자에게 Cloudflare 계정만 있으면 된다.
→ 신제형: **"[[hypeproof-studio|스튜디오]]에 녹일 수 있겠다."** 제품화 후보.
(우리 배포 스택도 이미 Cloudflare 터널이다 — 운영 지식이 겹친다.)

## 가격

**1일 60만원/인** 제안. 근거는 팀의 시간 비용이다 — 2시간 세션 20만원 대비, **하루만 일하고 60만원**이면 시간 효율이 낫고 참가자의 이동 비용도 한 번으로 끝난다.

⚠️ 검토가다. 20명 모집 시 원가·정산 구조는 [[2026-09-06-weekly-on-hypeproof]] §5의 워크드 예시(20만원×20명 기준)와 **분모가 다르다**. 60만원안으로 정산을 다시 계산해야 한다.

| **풀데이 워크숍** | 이 문서 | 주말, 미정 |

### 10/7의 알려진 리스크

신제형: "URL 붙여서 배포까지는 되는데 **고객에게 퍼블리싱될 만한 퀄리티는 2시간 반으로는 안 나온다**. 스킬을 더 깎지 않는 한."

[[jay-lee]]의 답 — **레벨을 분리하라**:

> "**레벨 1은 케이블맨**이야. 레벨 1에 있는 사람을 어떻게 할 건지, 레벨 2로 간 사람을 어떻게 다시 후킹할 건지를 고민해야지, **모든 사람을 다 레벨업시킬 생각은 하면 안 된다.**"

즉 10/7은 **레벨 1용 후킹**이고, 풀데이는 레벨 2 이상을 받는 자리로 갈린다. 품질 목표를 전원에게 걸지 않는다.
