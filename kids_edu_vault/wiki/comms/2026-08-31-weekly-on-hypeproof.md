# Weekly on HypeProof — 2026-08-31

> 소스: [[weekly-on-hypeproof-20260831-source]] (Gemini 요약본 + 스크립트, 2시간 4분)

## ⭐ [[four-learner-experiences]]가 팀 확정을 받았다

8/30 시점 이 축은 **"아직 팀 확정 전, 열린 질문 1번"** 이었다. 8/31 회의에서 [[minhan-cho]]가 미션부터 제품까지의 구조로 발표했고 팀이 **결정 사항으로 채택**했다.

```
미션: AI가 일하는 세상에서 판단하는 인간을 기른다
  └ 네 가지 경험 → 7 Assets → 제품 3종 ([[chalk]] · [[hypeproof-studio]] · [[sediment]])
```

- 성공 지표: "AI 지식을 잘 배웠는가"가 아니라 **학습자가 스스로 정의한 문제를 AI와 함께 풀었는가**. [[hypeproof-mission]] 정본과 일치.
- 발표된 네 경험은 [[four-learner-experiences]]의 A~D와 같은 축이다 — 문제 정의 / 맥락 부여·위임 / 검증 루프 / 주인의식(증거로 남음).
- 7 Assets 열거: **눈 · 의도 · 맥락 · 위임 · 검증 · 반복 · 주인의식**.
- 세 제품이 유기적으로 연결돼야 학습자가 경험·에셋을 체득한다는 것이 발표의 핵심 주장.
- **완성된 것은 [[hypeproof-studio]] 하나**. [[chalk]]는 아이디어 단계, [[sediment]]는 미구축이라고 회의에서 재확인.

> [!key-insight] Chalk는 저장소가 아니라 생성기이고, 나아가 게이트다
> [[jinyong-shin]] 정정: 초크에 든 것은 강의가 아니라 **강의를 만들 재료와 우리의 방향성**이다. 대상과 전달할 바를 입력하면 **강의안을 만들어 주는 프레임워크**.
> 더 나아가 "이 강의가 HypeProof 교육관에 맞는가"를 검증해 외부 활용을 열어 주는 **게이트웨이**여야 한다.
> [[jesse-kim]]: **"크립토나이트는 스튜디오가 아니라 초크여야 한다"** — 시간당 20만 원을 받을 수 있는 킥.

[[sediment]]에 남아 있던 미확인 항목("세디먼트 / 크(?) / Studio")은 여기서 **Chalk로 확정**된다.

## 논의 흐름

### 1. 영업 체계 — 담당자를 붙인다

[[jay-lee]]가 혼자 지고 있던 세일즈를 분담. **세일즈 = "불씨를 살리는 역할"** 로 정의하고 전담 구역을 나눴다 → [[sales-ownership-by-vertical]].

- 자료 2종을 **분리**한다: 투자자·파트너용 **공통 IR 덱** ≠ 고객·채널용 **프로덕트 소개서**(기능·로드맵·모듈화 커리큘럼·BM 포함).
- 채널 파트너 예시로 Anthropic 한국 대표, OpenAI 관계자가 거론됐다.
- [[sk-biopharma]] 교육 이후 **대교** 측 문의가 들어왔다.
- 딜 관리 대시보드 도입 — Lead → Discovery → Qualified → WON. 팀원 업데이트 의무.

### 2. 가격과 시장 — 10만 원에서 20만 원으로 가는 길

[[jiwoong-kim]] 분석. 현재 시간당 약 10만 원, 목표 20만 원. 하버드 SSP·LaunchX·Stanford AI for All 대비 **20만 원대는 논문 멘토링·1:1 과외급에서만 성립**한다.

논문 대행·성과 확약 컨설팅은 법적 리스크로 배제하고, 대안으로 3단계를 제시:

1. AI 커뮤니티 형성
2. **표준화된 로그·성과 기록** — [[sediment]]의 존재 이유
3. 성공 사례 1건 창출 (기업 도입·투자 유치·매출)

> [!contradiction] 성공 사례 1건 의존 전략에 반론이 있다
> [[minhan-cho]]: 단일 성공 사례에 기대는 것은 **우연에 기대는 것**이다.
> [[jay-lee]]·[[jinyong-shin]]: "모두의 창업" 같은 대형 대회보다 **실 매출·상용화 경험**을 성공 기준으로 삼자.
> 최종 합의 없음. 9/15 문서에서 성공 사례의 정의를 다시 잡아야 한다.

제약 조건:
- 학부모의 실제 관심사는 **대학 진학**. 창업 캠프가 진학에 방해되지 않게 포지셔닝해야 한다 ([[jesse-kim]]: 창업 자체보다 진학·취업 도구로).
- **학원법** 저촉 고려 → 기존 커리큘럼 안에 창업 활동을 녹이는 방식 (신제형). [[teen-ai-startup-camp-v0]]의 "30일 초과 시 학원 등록 의무"와 같은 제약.
- SK플래닛 스마트틴 앱 대회 사례 참고 — 파트너 채널 대회 → 플랫폼 내 상용화 → 월 유지보수비 BM.

### 3. 재방문율 — "밑 빠진 독"

[[jesse-kim]]: 이벤트가 있을 때만 쓰이는 앱이 되면 안 된다. **스튜디오 프로덕트만 팔아서는 지속되지 않는다.**
대치동이 주는 SAT 점수·졸업장 같은 것을 우리는 아무것도 개런티할 수 없으므로, **리그를 통해 그것을 넘는 무언가**를 준다 → [[studio-subscription-league-model]].

- 샤크탱크형 피드백 패널로 심사·참여 유도.
- **"기능 완성"보다 "운영 중"이라는 상태 유지**가 중요하다.
- [[jay-lee]]가 꼽은 최우선 개발 과제: **어드민/모니터링 페이지**(재방문율·운영 데이터 실시간 추적) + **강사용 학습 모니터링·피드백 도구**.
  - 이는 [[four-learner-experiences]]의 **D(증거로 남고 설명한다)** 커버리지 ⛔ 를 메우는 일이기도 하다.

### 4. 프로덕션 정비

[[jesse-kim]]: Apache 오픈소스 대비 **PR·이슈 관리가 체계적이지 못하고 브랜치가 중복**된다. 이것이 개발 철학의 혼선과 프로덕션 문제를 낳는다.
→ 9/19 밤샘 세션 확정, [[production-strategy-session-20260919]].

### 5. 9/15 피칭

- 문서 **2종 분리**: 9/15 당일용 / 장기 미션 얼라인먼트용.
- [[minhan-cho]]가 학생 창업 교육으로 AI-인간 협업 능력을 검증하고 단계적으로 확장하는 로드맵을 발표.
- [[jiwoong-kim]]: 미션 중심 접근과 시장 중심 접근(전문직·학생)을 **통합**해, 교육 과정 구성과 커뮤니티 구축 방식을 녹여낼 것.

- [[jesse-kim]]: 대상이 달라도 HypeProof 전체를 관통하는 통합 교육 철학 **AKB(가칭)** 정의 필요.
- 표준화된 **인증 체계** 필요성 — 어떤 트랙을 거치든 동일한 평가 기준과 능력을 보장. ([[chalk]] 게이트웨이론과 이어진다)
